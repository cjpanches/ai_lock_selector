## PROJECT CONTEXT

You are helping prepare training data for a YOLO computer vision model that will detect and measure врезные дверные замки (mortise door locks) from photos.

## PROJECT GOAL

Build a system that:
1. Takes a photo of a door lock from top-down view
2. Uses AR mask with Euro cylinder profile as scale reference
3. Detects lock components using YOLO
4. Measures dimensions with ±0.5-1.0mm accuracy
5. Matches against database of 147 locks

## CRITICAL REFERENCE DATA

### Euro Cylinder (Цилиндр) - THE MOST IMPORTANT OBJECT

**Engineering Drawing Available:** `/mask/euro_profile_exact.svg`

**Exact Dimensions:**
- Total height: 33mm
- Top circle: diameter 17mm (radius 8.5mm)
- **Slot width: 10mm** ← THIS IS THE CALIBRATION REFERENCE
- Bottom semicircle: diameter 10mm (radius 5mm)

**Shape:** Complex - looks like figure-8 but with flattened middle
- Top half: semicircle (17mm diameter)
- Middle: vertical rectangular slot (10mm wide)
- Bottom half: semicircle (10mm diameter)

**Why 10mm slot is critical:**
- Used for SCALE CALIBRATION
- Formula: pixels_per_mm = detected_slot_width_pixels / 10.0
- All other measurements depend on this calibration

## ROBOFLOW REQUIREMENTS

### Format:
- Export as: **YOLOv8 Oriented Bounding Box (OBB)**
- This supports rotated boxes for better fit on angled locks

### Classes to Create in Roboflow:
1. lock_plate
2. cylinder_hole
3. mounting_hole
4. handle_square

### Annotation Guidelines:

**cylinder_hole (MOST CRITICAL):**
- Draw polygon around the ENTIRE 33x17mm silhouette
- Include both top circle and bottom semicircle and the slot between them
- This is both a detection target AND the scale calibration reference
- Label accurately - model will use this for all measurements

**lock_plate:**
- Draw rectangle/polygon around entire visible metal plate
- Usually the largest rectangular object in frame

**mounting_hole:**
- 2 holes, usually vertically aligned
- Draw ellipse/circle around each
- Label ALL visible mounting holes

**handle_square:**
- Square or rectangular hole in middle/lower part
- Usually 8x8mm, 9x9mm, or 10x10mm
- Draw rectangle around it

## KEY INSIGHT FOR AI

The cylinder_hole (class 1) is special:
- It's an object to detect (for matching)
- It's ALSO the scale reference for ALL measurements
- The 10mm slot width is used to calculate pixels_per_mm
- Without this, no accurate measurements are possible
