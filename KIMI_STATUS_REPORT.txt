## 3. CRITICAL MEASUREMENTS

### Euro Cylinder Dimensions (KEY REFERENCE!)
- Total height: 33mm
- Top circle diameter: 17mm (radius 8.5mm)
- Slot width: 10mm <-- CRITICAL FOR CALIBRATION
- Bottom semicircle: 10mm diameter (radius 5mm)

### Calibration Formula:
```
pixels_per_mm = detected_slot_width_pixels / 10.0
```

## 11. KEY INSIGHT FOR KIMI

Самый важный момент для понимания проекта:

**Euro cylinder hole (класс 1) - это одновременно:**
1. Объект для детекции YOLO
2. Эталон масштаба для КАЛИБРОВки

**Калибровка работает так:**
1. YOLO находит отверстие цилиндра на изображении
2. Мы измеряем ширину СЛОТА (10mm) в пикселях
3. pixels_per_mm = slot_width_px / 10.0
4. Все остальные измерения умножаются на этот коэффициент

**Поэтому точность зависит от правильного определения именно 10mm слота!**
