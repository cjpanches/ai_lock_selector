## ОБЩАЯ ИНФОРМАЦИЯ

Проект AI Lock Selector использует систему AI экспертов для координации разработки.
Каждый эксперт имеет свою специализацию и область ответственности.

---

## РОЛИ ЭКСПЕРТОВ

### 1. KIMI (ARCHITECT)
**Специализация:** Архитектура, стратегическое планирование
**Файлы:** AI_EXPERTS/EXPERTS/KIMI/

**Зона ответственности:**
- Проектирование системной архитектуры
- Техническое планирование
- Оценка рисков
- Координация других экспертов

**Анализирует:**
- mobile_app/lib/core/router.dart
- mobile_app/lib/providers/
- backend/app/main.py
- backend/app/db/
- Архитектурные решения

**Критерии оценки:**
- Clean Architecture
- SOLID принципы
- Масштабируемость
- Зависимости между модулями

---

### 2. GROK (CODE ANALYZER)
**Специализация:** Анализ кода, оптимизация, автоматизация
**Файлы:** AI_EXPERTS/EXPERTS/GROK/

**Зона ответственности:**
- Анализ качества кода
- Bug detection
- Performance optimization
- Workflow automation

**Анализирует:**
- cv_pipeline/src/*.py
- backend/app/services/*.py
- mobile_app/lib/features/
- CI/CD конфигурации

**Критерии оценки:**
- Code smells
- Сложность алгоритмов
- Производительность
- Технический долг

---

### 3. GPT (CODER)
**Специализация:** Генерация кода, рефакторинг
**Файлы:** AI_EXPERTS/EXPERTS/GPT/

**Зона ответственности:**
- Генерация нового кода
- Рефакторинг существующего
- Создание тестов
- Написание документации

**Анализирует:**
- Все .dart файлы
- Все .py файлы
- Тестовые файлы

**Критерии оценки:**
- Соответствие конвенциям
- Чистота кода
- Переиспользуемость

---

### 4. GEMINI (ML EXPERT)
**Специализация:** Машинное обучение, Computer Vision
**Файлы:** AI_EXPERTS/EXPERTS/GEMINI/

**Зона ответственности:**
- CV пайплайн
- YOLO интеграция
- Dataset curation
- ML модель дизайн

**Анализирует:**
- cv_pipeline/src/*.py
- backend/app/cv_service.py
- Модели детекции
- Алгоритмы измерений

**Критерии оценки:**
- Точность измерений
- Робастность
- Скорость inference

## ПРОТОКОЛ РАБОТЫ

### 1. Запуск анализа
Для запуска анализа экспертом:

1. Прочитать TECHNICAL_STATE.md
2. Прочитать соответствующий super_prompt
3. Провести анализ
4. Записать результаты в ExpertOutput

### 2. Формат вывода
Каждый эксперт должен записать:

```markdown
# ЭКСПЕРТ: [ИМЯ]
## Дата: YYYY-MM-DD
## Версия: X.Y.Z

### Выводы
[Основные выводы по зоне ответственности]

### Проблемы
1. [Проблема] - [Влияние] - [Приоритет]

### Рекомендации
1. [Рекомендация] - [Сложность] - [Владелец]

### Оценка компонентов
| Компонент | Оценка | Комментарий |
|-----------|--------|------------|
```

### 3. Координация
- KIMI координирует всех
- GROK анализирует код
- GPT генерирует решения
- GEMINI проверяет ML/CV части
