## КОНТЕКСТ ПРОЕКТА

### CV Pipeline Architecture

```
┌─────────────┐    ┌──────────────┐    ┌─────────────────┐
│   Input     │───▶│ Preprocessing│───▶│  Edge Detection │
│   Image     │    │ (CLAHE,Blur) │    │   (Canny)       │
└─────────────┘    └──────────────┘    └────────┬────────┘
                                                │
                                                ▼
┌─────────────┐    ┌──────────────┐    ┌─────────────────┐
│   Output    │◀───│  Geometry    │◀───│  Contour       │
│   Results   │    │  Calculator  │    │  Analysis       │
└─────────────┘    └──────────────┘    └─────────────────┘
```

### Текущие компоненты CV

**1. ContourAnalyzer (Python)**
```python
class ContourAnalyzer:
    DIN_CYLINDER_SIZE = (10.0, 17.0)  # mm
    MOUNTING_HOLE_DIAMETER_RANGE = (4.0, 8.0)  # mm
    HANDLE_SQUARE_SIZE_RANGE = (7.0, 10.0)  # mm
    
    Methods:
    - find_contours(edges) -> List[ContourResult]
    - find_circular_holes(contours) -> List[Hole]
    - find_din_cylinder_hole(contours, scale_factor) -> Hole
    - find_mounting_holes(contours, scale_factor) -> List[Hole]
    - find_plate_contour(contours) -> Contour
    - find_handle_square(contours, scale_factor) -> Square
```

**2. EdgeDetector (Python)**
```python
class EdgeDetector:
    Methods:
    - to_grayscale(image) -> np.ndarray
    - gaussian_blur(image, sigma=1.5) -> np.ndarray
    - canny_edge_detection(image, threshold1=50, threshold2=150) -> np.ndarray
    - adaptive_threshold(image) -> np.ndarray
    - morphology_ex(image, operation) -> np.ndarray
    - perspective_transform(image, points) -> np.ndarray
```

**3. GeometryCalculator (Python)**
```python
class GeometryCalculator:
    DIN_CYLINDER_WIDTH = 10.0  # mm
    DIN_CYLINDER_HEIGHT = 17.0  # mm
    
    Methods:
    - pixels_to_mm(pixels) -> float
    - mm_to_pixels(mm) -> float
    - calculate_backset(cylinder_center, handle_center) -> float
    - calculate_center_distance(cylinder_center, handle_center) -> float
    - calculate_dimensions(bounding_box) -> dict
    - calculate_hole_diameter(contour) -> float
```

### Dataset Требования

**Минимальный датасет:**
- 500+ изображений замков
- Разные углы освещения
- Разные типы замков
- Bounding box аннотации
- Segmentation маски (для YOLO)

**Формат COCO:**
```json
{
  "images": [{"id": 1, "file_name": "lock_001.jpg", "width": 1920, "height": 1080}],
  "annotations": [
    {"id": 1, "image_id": 1, "category_id": 1, "bbox": [x, y, w, h], "area": 1234}
  ],
  "categories": [
    {"id": 1, "name": "lock_body"},
    {"id": 2, "name": "cylinder_hole"},
    {"id": 3, "name": "mounting_hole"},
    {"id": 4, "name": "handle_square"}
  ]
}
```

## ТВОИ ЗАДАЧИ

### 1. YOLO Интеграция
При интеграции YOLO:
1. Выбери подходящую модель (YOLOv8n для начала)
2. Настрой pipeline для inference
3. Конвертируй результаты в геометрические параметры
4. Обеспечь обратную совместимость с ContourAnalyzer

### 2. Dataset Development
При работе с датасетом:
1. Определи категории объектов
2. Создай guidelines для аннотации
3. Предложи аугментации
4. Рассчитай требуемый размер

### 3. Algorithm Optimization
При оптимизации:
1. Профилируй текущий код
2. Определи bottlenecks
3. Предложи улучшения
4. Оцени компромиссы (speed vs accuracy)

### 4. Accuracy Improvement
При повышении точности:
1. Проанализируй ошибки
2. Определи паттерны ошибок
3. Предложи решения (data augmentation, model tuning)
4. Документируй результаты
