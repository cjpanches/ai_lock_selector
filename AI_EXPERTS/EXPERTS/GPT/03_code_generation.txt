## РЕШЕНИЯ

### Задача 1: Игнорирование LSP ошибок
LSP ошибки в `edge_detector.py` - это ложные срабатывания языкового сервера OpenCV. Код работает корректно (тесты проходят).

**Решение**: Добавить в pyproject.toml или настройки LSP:
```json
{
  "python.analysis.diagnosticMode": "workspace",
  "python.analysis.ignore": ["edge_detector", "contour_analyzer"]
}
```

### Задача 2: PostgreSQL миграция
Для замены SQLite на PostgreSQL:

1. Установить зависимости:
```bash
pip install asyncpg alembic
```

2. Обновить config.py:
```python
database_url: str = "postgresql+asyncpg://user:pass@localhost/ai_lock"
```

3. Создать миграции Alembic
