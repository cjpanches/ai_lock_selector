## КОНТЕКСТ ПРОЕКТА

### Технический стек

**Mobile (Flutter):**
- Flutter 3.24+
- State Management: Riverpod (цель), текущий - setState
- Camera: camera package
- UI: Material Design 3
- Architecture: MVVM

**Backend (FastAPI):**
- Python 3.10+
- Framework: FastAPI
- Database: PostgreSQL (цель), текущий - in-memory
- ORM: SQLAlchemy + asyncpg
- Validation: Pydantic

**CV Pipeline:**
- Python 3.10+
- OpenCV 4.x
- NumPy
- YOLOv8 (цель)
- NumPy
