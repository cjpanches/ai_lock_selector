# РЕВЮ СИСТЕМЫ ЭКСПЕРТОВ

## 1. АНАЛИЗ ТЕКУЩЕГО СОСТОЯНИЯ

### 1.1 Проблемы

| Проблема | Описание | Влияние |
|----------|----------|---------|
| Дублирование | subsystem1 + SUBSYSTEM_01_KIMI | Путаница |
| Именование | `IDEAL PLAN` vs `IDEAL_PLAN` | Ошибки |
| Пустая папка | INFO/GENERAL_PLAN пустая | Мусор |
| Неполная структура | У разных экспертов разные файлы | Несогласованность |
| Разные форматы | Grok - код, KIMI - текст | Нет унификации |

### 1.2 Текущая структура

```
ai_lock_project/
├── subsystem1/                      # Grok эксперт (Python)
│   ├── subsystem1.py               # Код
│   ├── INFO/Grok/                  # Анализ
│   └── ...
│
└── SUBSYSTEM_01_KIMI/              # KIMI +GPT+Gemini+Copilot (Текст)
    ├── INFO/KIMI/
    ├── INFO/GPT/
    ├── INFO/Gemini/
    ├── INFO/Copilot/
    └── ...
```

## 2. ПРЕДЛАГАЕМАЯ ОПТИМИЗАЦИЯ

│   │   ├── config.yaml

### 2.2 Преимущества единой структуры

- Унифицированное именование файлов

- Легкость добавления новых экспертов
- Централизованное управление

## 4. КОНФИГУРАЦИЯ ЭКСПЕРТА (config.yaml)

```yaml
expert:
  name: "GPT_CODER"
  version: "1.0.0"
  role: "Code Generation"
  api_key_env: "OPENAI_API_KEY"

capabilities:
  - code_generation
  - refactoring
  - code_review

files:
  input: "01_input_data.txt"
  methodology: "02_methodology.txt"
  results: "03_analysis_results.txt"

constraints:
  max_file_size: "100KB"
  timeout_seconds: 300

dependencies:
  - grok
  - kimi
```
