### 2. VS Code Configuration

Настраивай `.vscode/settings.json`:
```json
{
  "editor.formatOnSave": true,
  "editor.rulers": [100],
  "files.exclude": {
    "**/.dart_tool": true,
    "**/build": true
  },
  "[dart]": {
    "editor.formatOnSave": true,
    "editor.selectionHighlight": false
  },
  "[python]": {
    "editor.formatOnSave": true
  }
}
```

### 4. Task Automation

Создавай VS Code tasks:
```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Flutter: Analyze",
      "type": "shell",
      "command": "flutter analyze",
      "problemMatcher": ["$dart"],
      "group": "test"
    },
    {
      "label": "Backend: Run",
      "type": "shell", 
      "command": "cd backend && uvicorn app.main:app --reload",
      "problemMatcher": []
    }
  ]
}
```
