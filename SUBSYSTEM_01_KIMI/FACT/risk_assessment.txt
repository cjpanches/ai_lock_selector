## ШКАЛА ОЦЕНКИ

| Вероятность | Балл | Описание |
|-------------|-------|----------|
| Очень низкая | 1 | < 10% |
| Низкая | 2 | 10-30% |
| Средняя | 3 | 30-50% |
| Высокая | 4 | 50-70% |
| Очень высокая | 5 | > 70% |

| Влияние | Балл | Описание |
|---------|-------|----------|
| Критическое | 5 | Блокирует проект |
| Высокое | 4 | Существенное влияние |
| Среднее | 3 | Задержка 1-2 недели |
| Низкое | 2 | Легко преодолимо |
| Минимальное | 1 | Не влияет на сроки |

**Рейтинг риска = Вероятность × Влияние**

## ИДЕНТИФИЦИРОВАННЫЕ РИСКИ

### R1: Нет YOLO модели (CV Pipeline)
- **Вероятность**: 4/5
- **Влияние**: 5/5
- **Рейтинг**: 20/25 (КРИТИЧЕСКИЙ)
- **Описание**: Без ML модели CV не будет работать на реальных данных
- **Стратегия митигации**: 
  - Начать с pre-trained модели
  - Собрать dataset параллельно
  - Использовать transfer learning
- **Срок**: 2 месяца

### R2: CV точность < 70%
- **Вероятность**: 4/5
- **Влияние**: 4/5
- **Рейтинг**: 16/25 (ВЫСОКИЙ)
- **Описание**: Алгоритм может не распознавать замки в реальных условиях
- **Стратегия митигации**: 
  - Собрать 500+ фото разных замков
  - Тестировать на разных условиях освещения
  - Итеративно улучшать модель
- **Срок**: 3 месяца

### R3: Нет PostgreSQL (Backend)
- **Вероятность**: 1/5
- **Влияние**: 4/5
- **Рейтинг**: 4/25 (НИЗКИЙ)
- **Описание**: In-memory storage не масштабируется
- **Стратегия митигации**: 
  - Использовать SQLite для MVP
  - Мигрировать на PostgreSQL позже
- **Срок**: 2 недели

### R4: Плохой state management
- **Вероятность**: 2/5
- **Влияние**: 3/5
- **Рейтинг**: 6/25 (СРЕДНИЙ)
- **Описание**: Plain setState усложнит поддержку
- **Стратегия митигации**: 
  - Внедрить Riverpod
  - Рефакторить существующий код
- **Срок**: 1 неделя

### R5: Нет unit тестов
- **Вероятность**: 3/5
- **Влияние**: 3/5
- **Рейтинг**: 9/25 (СРЕДНИЙ)
- **Описание**: Баги не будут обнаружены на ранних стадиях
- **Стратегия митигации**: 
  - Добавить базовые тесты
  - Настроить CI с тестами
- **Срок**: 2 недели

### R6: Dataset недостаточного качества
- **Вероятность**: 5/5
- **Влияние**: 5/5
- **Рейтинг**: 25/25 (КРИТИЧЕСКИЙ)
- **Описание**: ML модель требует качественных данных
- **Стратегия митигации**: 
  - Создать guideline для сбора
  - Провести ручную верификацию
  - Аугментация данных
- **Срок**: Параллельно с разработкой

### R7: Неполная AR реализация
- **Вероятность**: 2/5
- **Влияние**: 3/5
- **Рейтинг**: 6/25 (СРЕДНИЙ)
- **Описание**: AR может не работать на всех устройствах
- **Стратегия митигации**: 
  - Fallback на ручной ввод
  - Тестирование на разных устройствах
- **Срок**: 1 месяц

### R8: Flutter Web/PWA не поддерживает камеру
- **Вероятность**: 3/5
- **Влияние**: 2/5
- **Рейтинг**: 6/25 (СРЕДНИЙ)
- **Описание**: Camera plugin ограничен мобильными платформами
- **Стратегия митигации**: 
  - Фокус на native mobile
  - PWA как вторичная платформа
- **Срок**: N/A
