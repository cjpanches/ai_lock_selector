## ЗАДАЧА 1: Внедрить Riverpod (P0)

### Описание
Заменить plain setState на Riverpod для state management в Flutter приложении.

### Текущий код
```dart
class _ARCameraScreenState extends State<ARCameraScreen> {
  Offset _maskPosition = const Offset(0.5, 0.3);
  double _maskScale = 1.0;
  // ... plain setState everywhere
}
```

### Требования
1. Создать `mask_position_provider.dart` с StateNotifier
2. Создать `camera_controller_provider.dart` с StateNotifier
3. Обновить `ar_camera_screen.dart` использовать ConsumerWidget
4. Добавить dependency: `flutter_riverpod: ^2.4.0`

### Критерии приёмки
- [ ] Нет прямого использования setState
- [ ] Все state управляется через providers
- [ ] Приложение запускается без ошибок


## ЗАДАЧА 3: Подключить PostgreSQL (P0)

### Описание
Заменить in-memory данные на PostgreSQL базу данных.

### Структура БД
```sql
CREATE TABLE manufacturers (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    country VARCHAR(100)
);

CREATE TABLE locks (
    id SERIAL PRIMARY KEY,
    manufacturer_id INTEGER REFERENCES manufacturers(id),
    model VARCHAR(255),
    backset FLOAT,
    center_distance FLOAT,
    plate_width FLOAT,
    plate_height FLOAT,
    mounting_holes_distance FLOAT
);
```

### Требования
1. Добавить `asyncpg` и `sqlalchemy` в requirements.txt
2. Создать `backend/app/db/database.py` с подключением
3. Создать `backend/app/db/models.py` с SQLAlchemy моделями
4. Создать миграции в `backend/app/db/migrations/`

### Критерии приёмки
- [ ] Подключение к PostgreSQL работает
- [ ] CRUD операции работают
- [ ] API endpoints возвращают данные из БД
