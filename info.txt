📐 Как будет работать AR-режим совмещения
Приложение показывает полупрозрачную маску цилиндрового отверстия DIN.

Пользователь двигает телефон и накладывает маску поверх отверстия замка.

Когда маска идеально совпала:

система фиксирует результат,

вычисляет масштаб,

определяет углы наклона,

корректирует перспективу.

Затем ИИ автоматически:

детектирует положение корпуса замка,

определяет границы,

считывает размеры.

После этого все размеры — это уже задача простой геометрии.

распознавания краёв корпуса,

📐 4. Алгоритм измерений: полная математика
После совмещения маски DIN-отверстия нам известны:

- эталон ширины отверстия (10 мм)
- эталонная форма → пропорции
- центр цилиндра
Далее:

1) Определяем коэффициент масштаба:
scale = 10 мм / width_in_pixels(узкая часть отверстия)
2) Используем OpenCV:
findContours → находить границы корпуса

edge detection → выделить планку

HoughLines → уточнить линии корпуса

perspectiveTransform → привести плоскость к прямой проекции

3) Вычисляем размеры:
backset = расстояние(центр цилиндра → край корпуса) * scale
межосевое = расстояние(центр цилиндра → центр паза ручки) * scale
длина планки = (верхняя точка → нижняя точка по планке) * scale
ширина планки = ширина в пикселях * scale
габариты корпуса = max_x - min_x, max_y - min_y * scale

🧮 8. Алгоритм подбора замка
Пусть размеры из фото → spec_user.

Шаги:
Вычисляем score для каждого замка:

score = 
  w1 * |backset_user - backset_db| +
  w2 * |center_dist_user - center_dist_db| +
  w3 * |plate_width_user - plate_width_db| +
  w4 * |body_height_user - body_height_db|
Нормируем и сортируем.

Берём:

если score < 5% → идеальный кандидат

если 5–20% → близкие

20% → альтернативы

Возвращаем JSON.

7. Алгоритм измерения
7.1. Масштаб:
scale = 10 мм / pixel_width(узкая часть профиля DIN)
7.2. Центр цилиндра: из центра маски.
7.3. Корпус:
segment → contours → bounding box

7.4. Backset:
backset = (distance(center_cylinder → edge_body) * scale)
7.5. Межосевое:
distance(center_cylinder → center_handle_square) * scale
8. Система подбора замка
8.1. Score-метрика
score = Σ wi * |user_param - db_param|
8.2. Категории:
score < 5% → идеальное совпадение

5–20% → близкие варианты

20% → альтернативы

✔ Стандартные значения: ~55, 72, 85, 90 мм (зависит от типа двери/замка). 

2. Межосевое расстояние
✅ Что это: расстояние между центром отверстия под ручку (квадрат) и центром отверстия под цилиндр.
📏 Почему важно: определяет, подойдут ли ручки и корпус замка без переделки двери.
✔ Часто встречающиеся стандарты: ~72 мм, 85 мм, 90 мм. 

3. Габариты корпуса замка
📏 Длина, высота и глубина (толщина) корпуса механизма.
✔ Эти размеры позволяют убедиться, что замок физически влезет в полость двери и не выступает наружу. 

4. Размеры лицевой / торцевой планки
📏

высота (длина)

ширина

форма края (закруглённая/квадратная)

✔ Эти параметры важны для совмещения с ответной частью и эстетики установки. 

5. Диаметр и расположение отверстия под цилиндр
📏 Особенно критично для цилиндровых замков, где отверстие стандартизовано.
✔ Эти параметры входят в AR-калибровку маски и являются основой для вычисления масштаба. 

6. Диаметр/размер паза под квадрат ручки
📏 Типичный паз ~8–10 мм, но встречаются вариации.
✔ Приложение должно определить положение и размер этого паза, поскольку он участвует в межосевом расстоянии. 

7. Расстояние до крепёжных отверстий
📏 Расположение отверстий под крепёжные винты на планке/корпусе.
✔ Нужен для совпадения бэк-плиты и верного положения замка в двери, особенно при замене старой модели. 

🔎 Дополнительные технические параметры (опционально)
Эти параметры не обязательно измерять по фото, но они важны для правильной идентификации модели в каталоге:

📌 Толщина дверного полотна
✔ Влияет на выбор длины штифта ручки/цилиндра и крепёжных элементов. 

📌 Диаметр ригелей и вылет ригеля
✔ Для многозапорных систем, особенно в бронированных дверях. 

📌 Класс взломостойкости / длина ключа / количество ригелей
✔ Эти параметры не измеряются фотографией, но используются для бизнес-логики подбора. 

📌 Схема измерений, которую приложение должно учитывать
На основе этих параметров можно сформировать такой краткий список размеров, которые приложение должно вычислять:

№	Наименование	Изображение / AR-маска	Измеряется через фото
1	Backset (B)	📌 Маска DIN отверстия	да
2	Межосевое (C)	📌 Паз ручки + отверстие цилиндра	да
3	Корпус: длина	📐 Контур корпуса	да
4	Корпус: высота	📐 Контур корпуса	да

6	Торцевая планка	📐 Контур планки	да
7	Крепёжные отверстия	📐 Контур крепёжных точек	да
8	Диаметр отверстия цилиндра	📌 Маска DIN	да

📌 Что важно для подбора в каталоге компании
При сравнении измеренных параметров с базой замков, критически важны:

✔ комбинация Backset + межосевое расстояние

✔ положение/диаметр пазов и отверстий

✔ размеры планки

Если параметры совпадают, замок можно считать заменяемым без доработки двери. Если параметры близки, приложение должно выдавать альтернативы с указанием возможных различий (наличие переходников, рамок, дополнительной обработки).

# Технология AR-измерений

## 1. Базовая идея
Использование стандартизированного отверстия DIN цилиндра как эталона размера.

## 2. Маска DIN
Маска содержит:
- овальное отверстие профиля Euro-DIN
- четыре контрольные точки
- слой прозрачной геометрии

## 3. Процесс
1. Пользователь совмещает маску с реальным отверстием.
2. AR SDK фиксирует расстояние между маркерами маски.
3. Масштаб = реальный размер DIN / размер на экране.
4. Все вычисления делаются в реальных мм.

# Алгоритм подбора замка

## 1. Жёсткое сравнение
если abs(backset1 - backset2) <= 1 мм
и abs(center1 - center2) <= 1 мм → кандидат

## 2. Soft Matching
Рейтинг R = Σ параметров (1 − |A − B| / порог)
